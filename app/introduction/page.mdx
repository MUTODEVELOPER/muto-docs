# Introduction

<p className="doc-lead"><strong>MUTO</strong> is an AI ecosystem built around live blockchain intelligence on <strong>BNB Chain</strong>. The product is designed to observe verifiable on-chain activity, structure it into useful intelligence layers, and give the MUTO Agent stronger context about what is happening now.</p>

## Product Thesis
<div className="vision-panel">Most crypto assistants begin with a user question and then fetch isolated market information. MUTO is building a persistent intelligence layer beneath the Agent — one that continuously observes the network and structures that activity before interpretation.</div>

<div className="pipeline"><span>CHAIN</span><i>→</i><span>DEX</span><i>→</i><span>TOKEN</span><i>→</i><span>WALLET</span><i>→</i><span>AI CONTEXT</span></div>
