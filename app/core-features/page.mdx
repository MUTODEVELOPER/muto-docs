# Core Features

<p className="doc-lead">MUTO combines live BNB Chain data collection, DEX intelligence, wallet-level observations, alerts and AI interpretation into one technical stack.</p>

<div className="section-grid">
<div className="tech-panel"><span className="eyebrow">Network Layer</span><h3>BNB Chain Pulse</h3><p>Direct network sampling provides recent-block context including TPS, transactions per block, unique wallets, contract interactions, transferred BNB and gas conditions.</p></div>
<div className="tech-panel"><span className="eyebrow">DEX Layer</span><h3>PancakeSwap Activity & Flow</h3><p>MUTO observes verified PancakeSwap infrastructure, maps router transactions to decoded V2/V3 swap events, resolves token metadata and builds structured DEX activity context.</p></div>
<div className="tech-panel"><span className="eyebrow">Baseline Engine</span><h3>DEX Anomaly Engine</h3><p>Rolling snapshots create short- and longer-term baselines so current activity can be compared with recent behavior across volume, traders, swaps and directional flow.</p></div>
<div className="tech-panel"><span className="eyebrow">Token Layer</span><h3>Token Radar</h3><p>Activity-first ranking built from observed PancakeSwap swaps, traders, flow, volume and acceleration. Canonical quote assets are identified by contract address rather than symbol.</p></div>
<div className="tech-panel"><span className="eyebrow">Wallet Layer</span><h3>Wallet Intelligence</h3><p>Routed swaps are mapped to transaction wallets to build descriptive observations across volume, tokens, pools, directional coverage and rolling behavior profiles.</p></div>
<div className="tech-panel"><span className="eyebrow">Pattern Layer</span><h3>Multi-Wallet Activity</h3><p>MUTO can identify multiple distinct wallets interacting with the same token in a close observation window. Synchronized activity describes temporal proximity only.</p></div>
<div className="tech-panel"><span className="eyebrow">Monitoring Layer</span><h3>Alerts</h3><p>The Alerts workspace provides configurable signal monitoring and delivery for observed activity, with web and Telegram surfaces.</p></div>
<div className="tech-panel"><span className="eyebrow">AI Layer</span><h3>MUTO Agent</h3><p>The Agent interprets the structured intelligence stack so its reasoning can use live BNB Chain context rather than isolated market data alone.</p></div>
</div>
